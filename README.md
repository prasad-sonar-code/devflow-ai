# ⚡ DevFlow AI

> Paste your failed CI/CD pipeline log. Get the root cause and exact fix in seconds.

## 🚀 Live Demo
Open `frontend/index.html` in your browser while backend is running.

## 🛠️ Tech Stack
- FastAPI (Python backend)
- OpenAI GPT (AI analysis)
- Vanilla JS + HTML (frontend)

## ⚙️ Run locally
```bash
cd backend
pip install fastapi uvicorn openai python-dotenv
uvicorn main:app --reload --port 8000
```
Open `frontend/index.html` in browser.

## 🎯 What it detects
- Permission/IAM errors
- Network timeouts
- Docker image issues
- Test failures
- OOM errors
- Disk space issues
